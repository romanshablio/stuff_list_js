# stuff_list_js

A small JavaScript application for managing an employee list in the browser.

The app displays a table of employees, calculates age and work experience, allows adding new employees through a form, and supports table sorting by columns.

## Features

- Employee table rendering.
- Add employee form.
- Sorting by full name, birth date, work start year, and position.
- Age calculation.
- Work experience calculation.
- Vanilla JavaScript modules.

## Technologies

- HTML.
- CSS.
- JavaScript modules.
- Bootstrap 5.

## Running

Open `index.html` in a modern browser.
